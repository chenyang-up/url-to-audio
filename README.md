AI Skill

从视频链接（Bilibili BV 号等）提取音轨到本地，默认 m4a 原样复制，可选 mp3/flac/alac/wav。当用户给出视频链接并要「提取音频/转成 mp3/flac」时触发。
提取的文件默认在‘桌面’，也可在对话指定它生成位置

默认是 chrome上拿去登录信息，当然不登录也是可以进行提取的，只是可能音质差一点点。若是在其他浏览器登录的 在对话时指定浏览器即可 （`-b chrome` /`-b safari` /`-b firefox`）
若是视频支持高的音质（大部分可能需要登录信息或者VIP），先切换到高音质播放，再复制链接提取

当链接是合集链接时，默认只提链接指向的那一个 P （对显式单 P 链接零歧义）；
若是想对整个集合进行提取，对话说「整个合集」；
