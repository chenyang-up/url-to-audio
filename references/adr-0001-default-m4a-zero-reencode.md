# ADR-0001: 默认输出 m4a 原样复制，而非无损格式

- 状态：Accepted
- 日期：2026-09-21

## 背景

用户最初要求支持无损格式（FLAC / ALAC / WAV / AIFF）。但主流视频站（含 Bilibili）的音轨源几乎都是 **AAC（m4a，有损）**。对 DASH 流，等价于 HLS/DASH 流。

## 决策

- **默认输出格式 = `m4a`，零重编码（原样复制源音轨）。**
- 无损格式（flac/alac/wav）仅作**显式可选参数**，需用户主动指定。
- 平台/SDK 原生提供无损音轨时，指定无损格式才有实际增益；否则对提取出的有损源再编码，只会改变容器或减小体积，**不会**恢复失真。

## 后果

- 默认路径保真最优、体积最小、速度最快（无 ffmpeg 二次编码）。
- 想要 mp3/flac/wav 的用户须显式传 `-f`，且需理解「有损源转无损容器」的保真收益有限。

## 备选方案

- 默认 flac/wav：更符合"无损"直觉，但对有损源是伪收益且体积剧增——已否决。
- 仅 m4a：无法满足用户对无损容器的显式需求——已否决。
